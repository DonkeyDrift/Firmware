推荐方案

单 Network 卡 + AP/STA 标签页

删除独立 AP/STA 两张卡，新增一张 networkCard。左上角是 AP/STA 标签，右上角保留 STA 配置齿轮。

  • 默认：STA connected 时自动选 STA，否则选 AP。
  • 用户点击标签后，本页面会保持用户选择，不被自动刷新覆盖。
  • AP 页显示 AP SSID + AP IP + client 数。
  • STA 页显示 STA SSID + STA IP + connected/pending/disabled。
