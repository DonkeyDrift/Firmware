CH / STATUS 折叠符号方向选择

请比较 3 种下拉扩展符号。重点看：一眼能否理解“可展开”、是否适合 MUS4 Web Console 的紧凑调试界面。

A. 经典 Chevron：▸ / ▾
▸RC Channels6 channels
▾RC Channelsexpanded
CH1 Steering0 CH2 Throttle0 CH3 Park1500 CH4 Mode0 CH5 Drift1000 CH6 Scale1500
▸STATUS Detailsmode=0 park=1...

A：▸ / ▾

最常见、调试工具感强、占位窄。适合紧凑日志/状态面板。

B. 加减号：⊞ / ⊟ 或 + / −
⊞RC Channels6 channels
⊟RC Channelsexpanded
CH1 Steering0 CH2 Throttle0 CH3 Park1500 CH4 Mode0 CH5 Drift1000 CH6 Scale1500
⊞STATUS Detailsmode=0 park=1...

B：⊞ / ⊟

“展开更多”含义明确，但视觉稍重，和调试数值列表放在一起会更抢眼。

C. 文本胶囊：展开⌄ / 收起⌃
RC Channels展开⌄
RC Channels收起⌃
CH1 Steering0 CH2 Throttle0 CH3 Park1500 CH4 Mode0 CH5 Drift1000 CH6 Scale1500
STATUS Details展开⌄

C：展开⌄ / 收起⌃

最清楚，适合新手；但占空间，对 Web Console 顶部状态区略显啰嗦。

我初步推荐 A：▸ / ▾。它最省空间，符合调试控制台习惯，也适合后续给 STATUS 长字段做二级分组。
