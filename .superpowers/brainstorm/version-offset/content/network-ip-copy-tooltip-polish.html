Network IP 复制提示优化

按你的反馈：去掉 IP 下方虚线；悬停提示改为自定义浮层并向右偏移，避免遮挡 IP。

当前：虚线 + 原生 title

⚙
Network
192.168.3.144
SSIDHome WiFi

虚线会增加视觉噪声；浏览器原生 title 的位置不可控，可能遮挡 IP。

优化后：无虚线 + 右移提示

⚙
Network
192.168.3.144
SSIDHome WiFi

鼠标移到 IP 上方可看到右移后的提示标签。IP 本身不再有下划线，仅通过 hover 变蓝和鼠标手势表达可点击。

实现口径

  • 移除 .copyValue 中的 text-decoration、text-decoration-style、text-underline-offset。
  • 移除 networkValue 的原生 title 属性，避免浏览器默认提示不可控。
  • 新增 .copyValue:hover:after 自定义提示，内容为 点击复制 IP。
  • 提示使用 left:72px; top:-26px，比 IP 起点更靠右，避免遮挡主值。
  • 复制成功/失败的右下角 toast 保持不变。

请把鼠标移到“优化后”的 IP 上方查看提示。如果符合预期，请回复“确认”。
