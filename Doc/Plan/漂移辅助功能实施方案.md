# 漂移辅助功能实施方案

## Context

### 背景
MUS4 是基于 ESP32 的 RC 小车底盘固件，当前支持手动/半自动/全自动三种模式。本方案新增漂移辅助功能：当检测到车身尾部侧滑（过度转向）时，自动叠加反打舵角，帮助驾驶员保持漂移姿态的稳定。

### 核心物理约束
- MPU6050 的 gyroZ（Z轴偏航角速度）可直接反映侧滑：剧烈波动 = 侧滑发生
- **尾部顺时针滑移** → gyroZ 为负值 → 需要**向左**反打舵
- **尾部逆时针滑移** → gyroZ 为正值 → 需要**向右**反打舵
- 遥控器转向中值为 1439us（<1439向左，>1439向右），当前代码中值为 1488us，需注意映射对齐

### 现有代码可复用资源
- 已有 PID 控制框架（`process_steering_signal`，mus4.ino:1400-1507），变量结构可复用
- 主循环中已每帧读取 `sensor_data.gyroZ`（SharedTypes.h）
- CH3（Park通道）可复用作为漂移辅助的启用开关
- 已有 RC 信号滤波框架（滑动中值+移动平均）可直接复用处理 gyroZ 噪声

---

## 推荐方案：Gyro 开环补偿型漂移辅助

### 设计原则
- **非侵入式**：默认关闭，手动模式下独立工作，不影响半自动/全自动模式原有逻辑
- **可调参数**：阈值、增益、平滑系数均为可配置常量，便于实车调试
- **安全优先**：辅助输出仅做叠加补偿，不覆盖驾驶员的原始转向输入，超出舵机物理范围自动限幅

---

## 具体改动

### 1. 新增参数与数据结构（SharedTypes.h 或 mus4.ino 全局常量区）

新增漂移辅助相关常量：
```
DRIFT_ASSIST_ENABLED     // 是否全局编译启用（默认开启）
DRIFT_ASSIST_GAIN        // 反打增益系数，默认值 15.0（gyroZ单位 rad/s，乘以增益得到 ±100 控制值的补偿量）
DRIFT_ASSIST_THRESHOLD   // 侧滑触发阈值 rad/s，默认 0.8（低于此值认为正常行驶，不介入）
DRIFT_ASSIST_MAX_COMP    // 最大补偿角度（-100~100 范围内），默认 ±60，防止过度反打
DRIFT_ASSIST_SMOOTH      // 补偿量一阶平滑系数，默认 0.3，避免补偿输出抖动
```

新增全局状态变量：
```
drift_assist_active      // 布尔值，当前辅助是否正在介入
drift_compensation       // 当前补偿量（平滑后的最终值）
```

### 2. CH3 开关映射逻辑修改（mus4.ino 处理 RC CH3 的位置）
原 CH3 仅用于 Park 锁车，修改为三态映射：
- CH3 低位（≤1400us）→ Park 锁车
- CH3 中位（1400~1600us）→ 解锁 + 漂移辅助关闭
- CH3 高位（≥1600us）→ 解锁 + 漂移辅助开启

### 3. 新增 `apply_drift_assist()` 函数（建议放在 process_steering_signal 附近）
处理流程：
1. 仅在 **手动模式 + 漂移辅助开启** 时执行，其他模式直接返回原始转向值
2. 对 gyroZ 做一阶低通滤波（复用现有滤波思路），消除传感器噪声
3. 判断 |gyroZ| 是否超过触发阈值，未超过则补偿量指数衰减到 0
4. 计算反打补偿量：`compensation = -gyroZ * DRIFT_ASSIST_GAIN`（负号实现反打）
5. 对补偿量做 ±DRIFT_ASSIST_MAX_COMP 限幅
6. 将补偿量叠加到驾驶员原始 `car_output.steering` 上
7. 最终结果再次做 -100~100 限幅，确保不超出舵机物理范围

### 4. 控制流接入点（主循环 mus4.ino，PWM输出之前）
在手动模式下，`car_output.steering` 计算完成后、映射到 PWM 之前，调用 `apply_drift_assist()` 进行补偿。

**不修改**半自动/全自动模式的原有逻辑，避免对上位机自动驾驶控制造成干扰。

### 5. TUI 显示扩展（可选，TUI.cpp）
在现有仪表盘上新增漂移辅助状态显示：
- 开关状态（ON/OFF）
- 当前 gyroZ 数值
- 当前介入补偿量
- 介入状态指示（正在反打时高亮）

## 验证方案

### 台架验证（无需实车）
1. 编译上传固件，打开串口监视器 TUI
2. 用手快速转动开发板模拟侧滑，观察 TUI 中 gyroZ 和补偿量的变化
3. 将 CH3 拨到高位开启辅助，手动输入固定转向值，转动车身时观察最终输出舵角是否按预期反打

### 实车调试
1. 低速行驶，逐步提高 DRIFT_ASSIST_GAIN，直到反打响应明显但不抖动
2. 调整 DRIFT_ASSIST_THRESHOLD，避免正常转向时误触发
3. 调整 DRIFT_ASSIST_MAX_COMP，限制最大反打角度，防止过度修正造成甩尾

### 回归检查
- 辅助关闭状态下，手动模式转向响应完全等同于原有逻辑
- 半自动/全自动模式下，无论 CH3 位置如何，漂移辅助均不生效
- Park 锁车功能在 CH3 低位正常工作
