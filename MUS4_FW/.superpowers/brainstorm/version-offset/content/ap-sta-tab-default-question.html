AP/STA 合并卡片：默认显示哪个标签页？

目标是把 AP 与 STA 合并为一个 Network 卡片，左上角用 AP / STA 标签页切换。请先确认默认显示页。

建议

A. 默认 AP

Mode
Park
Drift
Voltage
APSTA
Network
192.168.4.1
clients 0

适合调试现场：AP 是设备 Web Console 的默认入口，断网时也最可靠。

B. 默认 STA

Mode
Park
Drift
Voltage
APSTA
Network
192.168.3.144
connected

适合日常联网使用：优先看 STA 地址和连接状态，但未配置或掉线时默认页可能显示 disabled/pending。

C. 自动选择

Mode
Park
Drift

APSTA

192.168.3.144
STA connected

STA 已连接时显示 STA，否则显示 AP。信息密度高，但切换规则更复杂，页面刷新时可能改变用户当前观察对象。

请回到终端回复：A / B / C。若无特别偏好，我建议选 A：默认 AP，并保留用户点击后的当前标签直到刷新页面。
