设计口径

  • 复制目标为当前 Network 标签页主值中的 IP：AP 页复制 ap_ip，STA 页复制 sta_ip。
  • IP 主值增加可点击样式：鼠标指针 + 虚线下划线；不影响标签按钮和齿轮。
  • 优先使用 navigator.clipboard.writeText()。
  • 若 Clipboard API 不可用或失败，降级使用隐藏 textarea + document.execCommand('copy')。
  • 成功提示：已复制 IP：192.168.x.x。
  • 失败提示：复制失败，请手动选择 IP。
  • 提示使用右下角 toast，不使用 alert()，约 1.6 秒后自动消失。
