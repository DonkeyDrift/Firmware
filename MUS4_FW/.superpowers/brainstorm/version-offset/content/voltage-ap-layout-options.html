VOLTAGE 卡片位置调整方案

目标：把 Voltage 放到 AP 左边，并让它紧挨 Drift。下面是当前布局与 3 个可选方案，建议选择 A。

A. 仅调整 DOM 顺序（推荐）

顺序改为 Mode / Park / Drift / Voltage / AP / STA。最符合“Voltage 在 AP 左边，挨着 Drift”，改动最小。

Mode Park Drift Voltage AP STA

B. DOM 顺序 + flex 固定权重

同时给 Voltage/AP/STA 明确 flex 宽度，减少换行差异；但会扩大 CSS 调整范围。

Mode Park Drift AP Voltage STA

C. CSS order 覆盖

不移动 HTML，只用 CSS 改视觉顺序；可行但源码阅读顺序与显示顺序不一致，不推荐。

请在浏览器点击一个方案，或直接在终端回复你的选择。
