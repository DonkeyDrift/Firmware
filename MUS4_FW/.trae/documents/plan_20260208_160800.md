# PID消抖与安全模式优化方案

## 1. 根本原因分析
- **无法退出 SAFE_MODE**：
  - **当前逻辑缺陷**：在 `process_steering_signal` 中，一旦 `safe_mode_active` 被置为 `true`，没有任何逻辑将其重置为 `false`。
  - **恢复机制缺失**：系统缺乏一个“连续正常信号计数器”来判定传感器是否已恢复正常。
- **小抖动问题**：
  - **现有滤波不足**：仅使用了 5 点滑动平均（MA），对于高频噪声有一定抑制，但缺乏对低频微小抖动的“死区”控制和动态响应调节（即 PID 的 D 项阻尼作用）。

## 2. PID 控制器设计
我们将实现一个基于 **位置式 PID** 的信号滤波器，用于平滑目标转向值。

- **输入 (Input)**: 经过 10 点滑动平均处理后的目标转向值。
- **输出 (Output)**: 最终发送给舵机的平滑转向值。
- **PID 参数 (初步)**:
  - **P (Kp = 0.6)**: 快速响应用户输入的幅度。
  - **I (Ki = 0.05)**: 消除稳态误差，确保最终值与目标一致。
  - **D (Kd = 0.2)**: 抑制超调，提供阻尼，减少抖动。
- **抗积分饱和**: 限制积分项 `integral` 在 `[-50, 50]` 范围内。

## 3. 实施计划

### Step 1: 优化安全模式逻辑
- **新增变量**: `valid_signal_count` (连续有效信号计数器)。
- **逻辑修改**:
  - 当检测到有效信号（`|S| <= 100`）时，`valid_signal_count++`。
  - 若 `valid_signal_count > 50` (约 1 秒)，自动退出安全模式：`safe_mode_active = false`。
  - 任意一次异常信号将重置 `valid_signal_count = 0`。

### Step 2: 实现 PID 类与缓冲区
在 `mus4.ino` 中添加 `PIDController` 结构体和相关变量：
- **滑动窗口**: 扩大至 `MA_WINDOW_SIZE = 10`。
- **PID 状态**: `prev_error`, `integral`。
- **死区控制**: 设置 `DEADBAND = 2`，当 `|error| < 2` 时不更新 PID，彻底消除静止时的微颤。

### Step 3: 重构 `process_steering_signal`
新的处理流程如下：
1.  **输入校验**: 保持原有的 `[500, 2500]` 范围检查。
2.  **前置滤波**: 更新 10 点滑动窗口，计算平均值 `target_steering`。
3.  **PID 计算**:
    - `error = target_steering - current_smooth_output`
    - 若 `|error| < DEADBAND`，强制 `error = 0`。
    - `output_change = Kp*error + Ki*integral + Kd*(error - prev_error)`
    - `current_smooth_output += output_change`
4.  **后置限幅**: `constrain(current_smooth_output, -100, 100)`。
5.  **安全监控**: 基于 PID 输出值判断是否触发安全模式（防止 PID 自身发散）。

### Step 4: 调试与验证
- **更新测试用例**: 修改 `run_steering_tests`，增加“故障恢复”测试（注入异常后，连续注入正常值验证是否退出安全模式）。
- **参数整定接口**: 代码中预留 PID 参数宏定义，方便调整。
