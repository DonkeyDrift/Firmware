# MUS4 Roadmap

本路线图只记录未来方向，不代表当前固件已经实现。

## 近期整理方向

- 为 Arduino CLI 原生编译补充更干净的临时 sketch 构建路径，避免把仓库内工具目录递归纳入 sketch 扫描。
- 给 `MUS4.h` 增加更细的段落目录，便于新读者快速定位配置、类型和 API。
- 按硬件安全风险补充上电前检查清单和台架验证清单。

## 后续可选方向

- 将 Web Console 页面资产生成流程文档化，避免手写维护大型 PROGMEM 字符串。
- 为串口与 Web Console 命令增加更完整的端到端硬件验证记录。
- 为 Pilot live mode 建立独立的安全演练流程。
